Briefing summary

Anthropic opens an always-on agent; rivals move coding agents into chat apps

A catch-up edition for two weeks. Claude gets its first agent that works while you are away, but only on a US waitlist. Cowork scheduled tasks stop losing their skills. Meanwhile Cursor, Devin and GitHub Copilot push agents into shared pages and Microsoft Teams.

Key. Watch = keep an eye on it · Try = worth testing this week · Skip = ignore · Gap = rivals have something Claude lacks · Claude has it = nothing new to do. Confidence 1–5 dots show how well sourced a claim is.

Your stack means the tools you use. Claude is the AI assistant made by Anthropic. Claude chat is the chatbot, Cowork is the desktop assistant for office tasks, and Claude Code is a coding tool. Cursor, Devin, GitHub Copilot, OpenAI Codex and Google Gemini CLI (command-line interface) are rival AI coding tools.

Your stack

Claude chat

Anthropic / Claude chatWATCH21 Oct 2026

Claude Duet, an AI assistant that carries out tasks while you are away, opens as a US-only waitlist

Anthropic (maker of the AI assistant Claude) describes Claude Duet as a proactive assistant: you hand it work by message, it runs on a computer run by Anthropic over the internet, not on yours, checks your linked accounts every few hours and comes back with a finished document, spreadsheet or slide deck, or with a question. It drafts replies and reminders but shows you what it is about to send, pay or delete and waits for your approval.

For now it is an early test version: only people in the US on Anthropic's two paid personal plans (Pro and Max) can join the waitlist. Business and company plans are excluded, and it counts against your usual allowance of messages.

Context & background. Duet is the first Claude product built around the idea that you do not open it; it comes to you. It checks accounts only every few hours, so it can miss something that arrives in between and may misjudge urgency, as Anthropic itself concedes.

The details. Anthropic lists scheduling meetings, flagging email and calendar items, finding unpaid invoices, preparing payroll for review and building dashboards or small web apps (the last uses more of your allowance). It can link to your email, calendar and other services through add-ons Anthropic lists in an online store. It will not buy or sell shares or move money between accounts, even with approval; credit card numbers and passport-type documents get the tightest protection. An automatic safety check, also used in Anthropic's other products, decides which actions are allowed. All of this is Anthropic's own description; no independent test has been published.

Why it still matters. Upgrade this to Try once you get an invitation or it opens outside the US. Anthropic has not said how Duet relates to Cowork, so do not assume it replaces tasks you set to run automatically at fixed times.

Cowork

Anthropic / CoworkTRY22 Oct 2026

Cowork tasks set to run automatically no longer lose your add-ons and saved instructions

Until this fix, a task set to run at fixed times, or one running in the background and not open on screen, could fail to find the add-ons (plugins) and saved instruction sets (skills) you installed. An example is a briefing you set to run every week. The fix arrived on 22 October.

Two related changes. Some actions need a human to approve them; these now ask for approval only inside the app, so an automatic task skips them rather than waiting. And the /schedule shortcut now just fills in a request to schedule a task, like the Schedule button.

Cowork (desktop app)

Context & background. Before this, an unattended run could behave differently from the same task run while you watched, because the saved instructions it relied on were not found. The symptom is a task that completes but ignores your own standing instructions.

The details. The approval change cuts the other way. An automatic task that needs a service insisting on a human click will now continue without that step, rather than stall. Check the output of any task that writes through such a service and note what was skipped. Anthropic's update notes do not list which services are affected.

Why it still matters. Anthropic's update notes do not say which add-ons were affected, and versions run through other companies' systems do not get this fix.

Claude Code

Anthropic / Claude CodeTRY27 Oct 2026

Adding the word ultrathink makes Claude work longer and more carefully on one request

In the text-command window of Claude Code, the word ultrathink inside your request makes Claude reason at its extra-high effort level for that one request, on all of Anthropic's current AI models. The word is now coloured only when it will work, not when it is quoted or part of a file name.

Try it on one demanding job, such as checking a contract for clauses that contradict each other.

Where

Context & background. Effort is the setting that decides how long Claude reasons before answering. It was previously changed with a menu or command for the whole session; the keyword raises it for one request only, so you do not pay for it on easy follow-ups.

The details. A fix in the latest update also stops the small status text at the bottom of the screen from naming a newly picked effort level before it takes effect: during a task it now shows the level actually in force. A change made mid-task may wait for your next message.

Why it still matters. Higher effort uses more of your allowance and takes longer. Anthropic does not say by how much.

Anthropic / Claude CodeWATCH19 Oct 2026

Claude Code warns before an old conversation uses up a large share of your five-hour allowance

On Anthropic's paid personal plans, picking up a long inactive conversation can use a noticeable share of the cap on how much you can use Claude within any five-hour stretch, because Claude has to reprocess the entire conversation. Claude Code now says so first and offers to start a new conversation instead, where Claude can look up the old one if you refer to it.

Related: the usage screen now explains each warning in one line and offers to apply the fix, and messages now say five-hour limit instead of session limit.

Cursor / DevinGAP16 and 26 Oct 2026

Two rival coding assistants now return interactive pages instead of only text and code

Cursor's AI helpers running online can build an interactive page (a "canvas") as part of their work, and you share the finished page with a team by link (16 October). Devin, a rival AI coding assistant, can build reports, dashboards and charts as web pages and show them inside the conversation (26 October).

Neither company says how the pages are made or saved.

Our guess (not reported): Claude's pages may start appearing inside the working conversation, not only as a link you open afterwards.

GitHub Copilot / DevinGAP15–23 Oct 2026

Coding assistants move into Microsoft Teams: tag the helper on a problem report and it prepares a fix

GitHub Copilot (the AI coding helper from GitHub, a code-sharing website) in Microsoft Teams can turn a notification into code: a problem report arrives in a channel, you tag GitHub, and the helper investigates and prepares a proposed code fix, a pull request, for people to check (23 October). Devin added matching Teams features on 19 and 23 October: it can start private work from channel messages, respond to group tags, and retry a crashed job when you reply in the thread.

GitHub also made its Slack and Teams apps work across several code projects on 15 October.

CursorGAP20 Oct 2026

Cursor lets you build your own AI helpers that react to code changes, Slack messages or a timer

Cursor's new toolkit for building your own AI helper lets you define it as a folder of instructions, tools and saved skills, then run it on your computer with a test area or put it on Cursor's servers with one command. The helper can react to proposed code changes and comments, results of automatic builds, Slack messages, automatic messages from other software, or a schedule, and keeps a separate conversation per thread. Templates include one that checks code for security problems and one that fixes proposed changes automatically.

Cursor says it is open to everyone, not just testers. Pricing is not stated.

Our guess (not reported): Anthropic may keep its developer tools and its Duet assistant on separate tracks until one hosted option covers both.

Editor's view

  1. The fortnight's biggest news is one you may not be able to use. Claude Duet is a US-only waitlist for Anthropic's two paid personal plans. Treat it as a sign of Anthropic's direction, not as this month's workflow.
  2. The practical gain is quiet and sits in Cowork. Automatic tasks finding their saved instructions is what lets a weekly briefing run unattended; check one run against last week.
  3. Where things are heading: AI assistants are moving out of the coding window into everyday apps. Claude Duet works on a computer run by Anthropic, Cursor builds helpers that react to events, Devin and Copilot sit in Teams, and Cursor and Devin hand back pages instead of text. Claude Code's own changes are about seeing and steering a long job. Our guess: Claude's next moves are more places to start tasks and better ways to receive results.

Little news from Google's Gemini CLI (command-line interface) tool: its latest update was 13 October, and free users were moved to a new Google tool called Antigravity.
