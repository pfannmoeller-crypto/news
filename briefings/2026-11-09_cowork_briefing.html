Cowork

Anthropic / Claude desktop appSKIP5 Nov 2026

The 5 November desktop release is fixes for Cowork tasks, nothing new to switch on

New cloud tasks no longer ask for a model you do not have access to, and tasks you import no longer use Memory after you or an administrator turned Memory off. A comment you add to a file in a task that can only read is now saved on the file instead of seeming to be sent.

If the app ever closed and reopened itself while getting ready to work, that loop is fixed too.

Claude Code

Anthropic / Claude CodeTRY6 Nov 2026

A new setting makes Claude Code runs that nobody watches refuse a permission question instead of waiting forever

With the new setting, an action that would stop and wait for your permission is refused and Claude carries on with the rest of the job. It applies in terminal sessions and to the helper agents Claude starts.

For a scheduled run nobody watches, such as your weekly briefing, this replaces a silent freeze with a visible refusal you can read afterwards.

Where
Claude Code (terminal)
What to do

Claude Code changelog, 6 Nov

Context & background. The setting is called "deny instead of prompting" and sits in the Claude Code settings next to the other permission choices. It arrived in the 6 November release together with a related change: if you have blocked a whole kind of command, a narrower "ask me first" exception is now refused rather than asked about.

The details. A denied action may mean part of the job is skipped. Read the end of the run for what was refused, and allow those actions explicitly if they are needed.

Why it still matters. Not stated: whether the desktop app's coding tab offers the same switch. The notes mention terminal sessions only.

Anthropic / Claude CodeTRY4 and 6 Nov 2026

Update Claude Code: three ways around its permission checks were closed this week

Update. Three gaps in Claude Code's permission checks were closed: one let a cleverly worded command hide part of itself from the check, one let a text-editing command skip the check in the modes where Claude stops asking you, and one let a command escape the safe test area when Claude makes a separate copy of a project to work in.

The same release fixes a case where rewinding a conversation could restore or delete a file through a shortcut to a folder.

Anthropic / Claude CodeWATCH4 Nov 2026

Claude Code now warns ten days before your claude.ai sign-in runs out

When you start Claude Code from the terminal with a single request, a one-line warning appears starting ten days before your saved claude.ai sign-in ends, and the command that shows your login status now shows the end date. When the sign-in does expire, the message says so and names the command to sign in again.

That matters for any job that runs without you at the keyboard.

What the others are building

CursorGAP6 Nov 2026

Cursor lets you talk to its coding agent in a live voice call and hear progress updates

In Cursor you can start a spoken call with an agent, describe a change out loud, ask what it is doing and hear short progress notes while it works. It runs in the app, the browser and the iPhone app, which can also start a call through Siri. The voice itself is provided by xAI's Grok Voice; with Cursor's Privacy Mode switched on, nothing is kept.

Read-across. Expect a two-way voice mode for Cowork and Claude Code on the phone, since you already read and direct your work on your phone [inference].

CursorGAP5 Nov 2026

Cursor can now build a small web app for you, give it a database and sign-in, and publish a link
