18–24 September 2026 · what you can do differently, and what the others are building

Briefing summary

Opus becomes the default everywhere, and Claude opens one shop window for the rest

Anthropic made Opus, its most capable model, the default on every paid plan, and opened one marketplace for the connectors and plugins that used to live in separate lists. Claude Code now reads a shared instructions file automatically. Cursor and Copilot both moved into security review of every pull request.

Claude chat

Anthropic / Claude chat WATCH 22–23 Sep 2026

Opus is now the default model on every paid Claude plan, not only the top ones

Starting a new chat, a Cowork session or a Claude Code run on the Pro or Team Standard plan now opens with Opus instead of Sonnet — the same default that Max, Team Premium and Enterprise plans already had. Anthropic is also setting how hard the model thinks to a medium level by default across every product, to keep answers quick.

Opus tends to read and write more carefully than Sonnet but costs more per exchange, so if you are on Pro or Team Standard your weekly usage allowance may run out sooner than it used to. There is nothing to turn on — if you would rather keep the cheaper, faster model, you can still pick it yourself from the model menu in chat and Cowork, or switch back in Claude Code.

Context & background. Until this week, only the most expensive Claude plans opened in Opus by default; Pro and Team Standard, the two cheapest paid tiers, opened in Sonnet, with Opus available as a manual choice. Anthropic's own guidance still describes Sonnet as the model that "handles most coding tasks well and costs less than Opus", so this is a default being raised, not a recommendation being withdrawn.

The details. The change reached Claude Code first, then the wider Claude app, including Cowork, within a day. It arrived alongside a new version of Opus that Anthropic says performs nearly as well as the previous Opus — the model it replaces — while costing less to run each time, part of why Anthropic felt comfortable making it the everyday default rather than a special-occasion one.

Why it still matters. If you run long Claude Code sessions or lean on Cowork through the week, this is the one change in this briefing most likely to change how quickly you hit your usage limit — worth a glance at your usage the first time it happens, rather than being surprised by it.

Anthropic / Claude chat TRY 23 Sep 2026

A single Claude Marketplace now lists every plugin, connector and partner agent in one place

Anthropic opened a marketplace that gathers more than two thousand connectors (links that let Claude read or work directly in outside apps, such as Google, Microsoft, Notion and Salesforce) and plugins (installable add-ons that give Claude new abilities), alongside ready-made Claude-powered agents and software you can buy directly, and consultants from Anthropic's own partner network. If your organisation already has a paid contract with Anthropic, money set aside under that contract can now be spent on these marketplace purchases too, instead of arriving as a separate bill.

Cowork

Anthropic / Cowork SKIP 21–22 Sep 2026

Cowork stops quietly losing the middle of long memory notes

If you kept a project memory note in Cowork longer than roughly ten thousand characters, and two updates to it happened to overlap, Claude could end up seeing only the beginning and the end of the note — the middle quietly disappeared, with no error or warning shown. That's fixed this week, so a long-running note about how you like a job done should now stay complete.

Also fixed: deleting a task on Windows no longer fails with an unhelpful error; sending a message that starts with a file path is no longer wrongly refused as an unrecognised instruction; and if a suggested connector belongs to a tool your organisation hasn't turned on yet, Cowork now offers to request it instead of showing a Connect button that would have failed anyway.

Claude Code

Anthropic / Claude Code TRY 18–21 Sep 2026

Claude Code now falls back to a shared, plain instructions file when a project has none of its own

If a project folder has no Claude-specific instructions file, Claude Code now reads a plain instructions file instead of starting with none — a text file, kept in the project, that lists things like coding conventions, what to avoid, and how to run tests, and that Claude then follows automatically. It's the same kind of file that other coding tools — including Cursor, OpenAI's Codex, and Google's command-line coding tool (one you run by typing commands, rather than clicking through a graphical app) — already read. Written once, it now works across whichever of those tools you happen to open that project in, instead of needing a Claude-only copy.

It reached the command-line version of Claude Code on 18 September and the desktop app's coding sessions three days later, so both places now behave the same way.

Anthropic / Claude Code TRY 23 Sep 2026

Claude Code can now tell you how many of your approval prompts auto mode would have handled

The built-in usage-insights view can now estimate, from your own recent sessions, how many permission prompts you answered by hand that auto mode — the setting that lets Claude approve routine actions itself — would have handled for you instead. That turns "should I turn auto mode on" from a guess into a number based on how you actually work.

Anthropic / Claude Code WATCH 19 Sep 2026

Auto mode's safety check gets cheaper for pay-per-use and enterprise users — not yet for subscription plans

If you access Claude Code through a pay-per-use developer account (billed by usage rather than a flat subscription), or through your organisation's own Amazon, Google or Microsoft cloud account rather than directly through Anthropic, the automatic check that decides whether auto mode can approve a routine action by itself now runs on Anthropic's side and no longer adds to your bill. This change does not reach the Pro, Max or Team subscription plans, so if you're on one of those, there is nothing different to notice yet.

What the others are building

Cursor GAP 23 Sep 2026

Cursor now scans every pull request for security holes and proposes the fix

Cursor added a reviewer that checks every pull request (a proposed code change, submitted for review before it's merged into the project) for exploitable weaknesses — injected code, ways to skirt authentication, secrets left in the code, and similar issues — and rates each finding by severity with the likely path an attacker would take and a suggested fix. A companion feature watches a change after it goes live, tracks whether it's behaving as expected, and can automatically open a pull request that reverts it — undoes the change, putting the code back the way it was — if something looks wrong.

Read-across. GitHub Copilot built a similar dedicated security check into its own reviews twice already this quarter; with Cursor now doing the same, three tools have converged on the same idea in a few months — expect Claude Code's own review feature to grow a comparable security-specific layer rather than staying a general reviewer [inference — a judgement call we're making, not something any source states directly].

Editor's view

  1. Opus is the new floor, not just the ceiling. Every paid plan, Pro included, now opens in Opus by default, with the thinking effort turned down to medium as a cost counterweight — the free ride on the cheaper model is over unless you switch back yourself.
  2. Claude built a front door for an ecosystem it already had. The new Marketplace doesn't add a capability so much as make two years of connectors, plugins and partner agents findable in one place — and, in a coincidence worth noting, Devin expanded its own plugin marketplace the very same week.
  3. The direction read: three habits are spreading across every serious agent tool at once. A plain-language dial for how hard the model should think, security-specific review of every pull request, and one shop window for everything pluggable. Claude Code already leads on the first of the three; expect the second to show up there before year's end, since two competitors just moved on it inside a single week.

A quiet week for headline features, a loud one for defaults — the change most people will actually notice is the one nobody had to switch on.
