Anthropic / Claude desktop appTRY22 and 27 Oct 2026 (missed in the 29 Oct edition)

Update the Windows app now: two bugs could delete files outside the folder Claude was working on

On Windows, deleting a folder in Claude could also delete files outside it, if the folder contained a shortcut to somewhere else or a mounted drive (fixed 27 October). Separately, the Reset App Data command could delete files outside Claude's own data folder (fixed 22 October).

This edition should have carried both a week ago. Update the desktop app today, and until you have, do not delete folders or use Reset App Data from inside Claude.

Context & background. Anthropic's notes give one line for each bug and name no number of affected users or files. The 27 October line speaks of a shortcut to another place, or a connected drive, inside the deleted folder. Anything linked into a project folder that way was at risk when you deleted that folder.

The details. The next desktop release on 3 November adds a related protection: starting a project from an existing folder no longer empties or replaces a file already in that folder. It also fixes some file links on Windows that would not open.

Why it still matters. If you ever deleted a folder or reset the app on Windows and later missed files, check the recycle bin and your cloud backup. Anthropic does not say whether deleted files can be recovered.

Anthropic / CoworkTRY3 Nov 2026

Automatic Cowork tasks now tell you when they fail instead of silently doing nothing

Until now a scheduled task could fail without a word, for example because a linked service had to be reconnected. Claude now notifies you when a run could not use such a service and when a run could not start at all.

This matters most for a weekly job such as your briefing run, where a silent failure meant discovering the gap days later.

Anthropic / Claude CodeTRY30 Oct 2026; fixed 4 Nov

Long conversations you leave idle are now summarised, so picking them up later costs less

In the desktop app's coding tab and in Visual Studio Code, a very long conversation (more than roughly 150,000 words) left idle is summarised. When you return after Claude's short-term memory of it has expired, Claude uses the summary instead of rereading everything.

You will notice cheaper restarts, and also that Claude may know a long old session only in summary. A 4 November update fixes a case where the summary was not really a summary.

What the others are building

GitHub Copilot / DevinGAP28 Oct and 2 Nov 2026

GitHub lets whole teams share an automated agent; Devin extends its own the same week

GitHub Copilot Automations, which are automated jobs that run in the cloud from an instruction, a trigger and a list of allowed tools, were personal until now. They can now be shared: everyone who can view a code project sees them, anyone who can change it edits them, the bill goes to the project owner and they keep running if the author leaves (28 October). Devin, a rival coding assistant, refined its own Automations on 2 November, for example by letting a Slack message start a job while ignoring chosen channels.

Read-across. Expect Cowork scheduled tasks to become shareable by a team, with someone else paying and a record of changes [inference].

Editor's view

  1. Update the Windows app first. Two file-deletion bugs were fixed on 22 and 27 October and last week's edition missed them. Everything else this week can wait.
  2. Two dates to note. Fast mode on Opus 4.8 ends on 30 November, and an administrator-set home view changes on 10 November. Neither needs action today, both need a date in your calendar.
  3. The direction read: guard rails and team ownership. Claude's own changes this week keep Claude inside its folder, tell you when a task fails and shorten long conversations. Rivals are making agents shared, event-driven and hosted inside other tools. Expect Cowork to follow with team-owned scheduled tasks.

A thin week for features and a useful one for trust: the useful changes are the ones that stop Claude doing things you did not ask.
