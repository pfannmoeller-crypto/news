9–12 November 2026 · what you can do differently, and what the others are building

Briefing summary

Claude chat gets sheets and whiteboards; rivals had a quiet three days

Three days after the last edition, Anthropic added shared spreadsheets and whiteboards to Claude chat and turned on the combined start screen for company-managed accounts. Scheduled tasks now say why they did not run. Cursor, Codex and Gemini CLI (command-line interface) shipped nothing worth your time.

Your stack

Claude chat

Anthropic / Claude chatTRY10 Nov 2026

Claude can now build spreadsheets and whiteboards that you and your team edit together

Claude Sheets and Claude Whiteboards are new kinds of document in Claude chat, both in beta on every paid plan. Ask for a tracker with tabs, formulas and drop-down lists and Claude fills the cells and marks each edit so you can follow it. A whiteboard is a shared board where Claude can group notes by theme and draft who does what.

Claude Dashboards also left beta on the same day and is now called Claude Data.

Claude chat (web, desktop, phone)

Context & background. Until now a spreadsheet from Claude was a file you downloaded and opened elsewhere. Now it stays in Claude and teammates can open it. Anthropic says an idea can carry from a whiteboard to a sheet to a dashboard without being retyped.

The details. Sheets are described as having simple spreadsheet functions for now; for full Excel features you export the file or use the separate Claude add-in for Excel. A whiteboard can be turned into a document or slide deck, or sent on to Miro or Lucid (online whiteboard tools). Claude Data adds written summaries of your data, agreed definitions of key numbers that a data team signs off (beta) and live sharing (beta). A feature called Claude Meetings, which would join a call and take notes, is announced as coming soon with no date.

Why it still matters. Anthropic names no limits on size, and I found no independent hands-on test of Sheets or Whiteboards yet, so treat the claims as the vendor’s. Check on a real tracker whether the formulas hold before you rely on it.

Anthropic / Claude chatWATCH10 Nov 2026

Apps from Asana, Notion, Box and others can now open beside your chat, and Claude can edit them live

Where a connected app supports it, you can open it next to the conversation or full screen, signed in as yourself, and ask Claude to change the page, row or file you have open. You approve its actions the same way as for any connector. It starts with a small group: Adobe, Atlassian, Box, HubSpot, Notion, Asana, Canva, Carta, Dropbox, monday.com, Smartsheet, Vercel and Webflow.

Context & background. Earlier this year Claude could only show a small live preview of a connected tool inside the chat. This is the full tool, not a preview.

The details. It arrives with the combined chat-and-Cowork experience, so you see it only once your account has been moved to it or your organisation switches it on. Administrators can limit a connector’s tools as they do today. Developers build these apps with Anthropic's open standard for connecting tools (the Model Context Protocol), and for them the feature is an early public test.

Why it still matters. Figma, Harvey and Shopify are named as building versions but are not available yet. Move this to TRY when an app you use daily appears in the list.

Cowork

Anthropic / Claude desktop appTRY10 Nov 2026

Scheduled tasks now tell you when the last run failed, needs you, or never started

A scheduled task’s card in Cowork and Code can now read “Last run failed”, “Last run failed, will try again”, “Needs input” or “Didn’t run”, and says why a due run has not begun, for example “Waiting for its previous run to finish”. Notifications are also more honest: a run that carried on without a step now says “skipped a step” instead of “completed”.

Context & background. Last time the question was how a run nobody watches should refuse instead of freeze. This is the other half: seeing afterwards what happened.

The details. A step that needed your approval while nobody was there is reported as skipped. In Auto mode (Claude acting without asking each time), a step blocked by the safety check is reported as blocked. Both are fixes to wording that used to say “completed”.

Why it still matters. Not stated: whether the status also shows in email or phone notifications. The note describes the task card and the notification text only.

Anthropic / Claude desktop appWATCH10 Nov 2026

Windows: Claude moves its data to a new folder, and may now stop at launch with a message

On Windows 10 (version 21H2 or later) and 11, the update moves Claude’s saved data to the folder Claude-Data under your local application data folder. If another program holds a file Claude needs, Claude can stop at launch with “Claude could not start”; closing other programs or restarting fixes it. When Windows starts Claude at sign-in it stops without any message.

Computer use now asks for the “Use system shortcuts” permission before pressing the Windows key with Tab, a number or a symbol, and file types that install something at a double click are refused.

Claude Code

Anthropic / Claude CodeTRY9 Nov 2026

Update Claude Code: a leak of sign-in secrets and two permission gaps were closed

Update. The 9 November release stops secrets such as refresh tokens (stored keys that keep you signed in) being sent to another server when a connected service redirects the sign-in, closes a case where a read-only command ran outside the protected area where commands are tested, without asking, and makes file-copy commands obey the same blocked-list as file writes.

What to do

Shipped

Context & background. The notes list 74 fixes; these are the ones that touch your security. They name no outside report and no known misuse.

The details. Also fixed: a file-editing command on network folders that could change only the first of several matching places or overwrite the first section of a notebook file. Commands typed with their full file location, such as /bin/cp (the copy command), now get the same checks.

Why it still matters. Updating is the whole action.

Editor's view

  1. The loud news is in Claude chat, the useful news is in Cowork. Sheets and whiteboards are new but beta and unproven; the scheduled-task status is small and answers the question you had last week about runs nobody watches.
  2. Update Claude Code again. The 9 November release closes a sign-in secret leak and two permission gaps, and quietly moves Fable 5.1 choices to 5.2.
  3. The direction read: work stays inside Claude. Sheets, whiteboards and apps that open beside the chat mean outputs no longer leave for another program, while Devin’s self-set reminders point the same way for unattended work. Expect Cowork runs that schedule their own next step [inference].

A short edition by design: Cursor, Codex and Gemini CLI (command-line interface) had nothing new since the last one, and Copilot’s (GitHub’s AI coding assistant) only entries were new models.
