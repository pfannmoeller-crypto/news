Your stack: Claude chat 2 stories

Claude chatTRYTOP10 Nov
Claude can now build spreadsheets and whiteboards that you and your team edit together
Claude Sheets and Claude Whiteboards are new kinds of document in Claude chat, both in beta on every paid plan. Ask for a tracker with tabs, formulas and drop-down lists and Claude fills the cells and marks each edit.
●●●●● 5/5
The details

Until now a spreadsheet from Claude was a file you downloaded and opened elsewhere; now it stays in Claude and teammates can open it. Sheets have simple spreadsheet functions for now; for full Excel features you export the file or use the separate Claude add-in for Excel. A whiteboard is a shared board where Claude can group notes by theme and draft who does what; it can be turned into a document or slide deck, or sent on to Miro or Lucid (online whiteboard tools). Claude Dashboards also left beta the same day and is now called Claude Data, with written summaries of your data, agreed definitions of key numbers (beta) and live sharing (beta). Anthropic names no size limits, and no independent hands-on test exists yet, so treat the claims as the vendor’s. Where: Claude chat on web, desktop and phone. Try it on an M&A (mergers and acquisitions) document tracker and check whether the formulas hold.

What to watch

Claude Meetings, which would join a call and take notes, is announced as coming soon with no date.

Claude chatWATCH10 Nov
Apps from Asana, Notion, Box and others can now open beside your chat, and Claude can edit them live
Where a connected app supports it, you can open it next to the conversation or full screen, signed in as yourself. Claude can then change the page, row or file you have open, with your approval.
●●●●● 5/5
The details

You approve Claude’s actions the same way as for any connector. It starts with a small group: Adobe, Atlassian, Box, HubSpot, Notion, Asana, Canva, Carta, Dropbox, monday.com, Smartsheet, Vercel and Webflow. Earlier this year Claude could only show a small live preview of a connected tool inside the chat; this is the full tool. It arrives with the combined chat-and-Cowork experience, so you see it only once your account has been moved to it or your organisation switches it on. Administrators can limit a connector’s tools as they do today. Developers build these apps with Anthropic’s open standard for connecting tools (the Model Context Protocol), and for them the feature is an early public test. Where: Claude chat, web and desktop app.

What to watch

Figma, Harvey and Shopify are named as building versions but are not available yet. Move this to TRY when an app you use daily appears in the list.

Your stack: Cowork 4 stories

CoworkTRYTOP10 Nov
Scheduled tasks now tell you when the last run failed, needs you, or never started
A scheduled task’s card in Cowork and Code can now read “Last run failed”, “Needs input” or “Didn’t run”, and says why a due run has not begun. A run that carried on without a step now says “skipped a step”, not “completed”.
●●●●● 5/5
The details

The card can read “Last run failed”, “Last run failed, will try again”, “Needs input” or “Didn’t run”, and it says why a due run has not begun, for example “Waiting for its previous run to finish”. A step that needed your approval while nobody was there is reported as skipped. In Auto mode (Claude acting without asking each time), a step blocked by the safety check is reported as blocked. Both are fixes to wording that used to say “completed”. Last time the question was how a run nobody watches should refuse instead of freeze; this is the other half, seeing afterwards what happened. Not stated: whether the status also shows in email or phone notifications. Where: Claude desktop app, Cowork and Code tabs. What to do: update and look at the card of your weekly briefing task.

CoworkWATCH10 Nov
The combined chat-and-Cowork start screen is now the default for company-managed accounts
Last edition flagged this for 10 November and it has now happened. On company-managed computers the combined “Unified Claude” start screen opens by default, with Cowork switched on.
●●●●● 5/5
The details

The separate switches for Chat and Cowork in the setup window are gone and replaced by one switch. On a personal account nothing is forced. The earlier plan said the combined view would go on for all organisations on 10 November; the newest app version keeps the old behaviour for setups that only use Code until 17 December. New conversations started on the project page now begin a Cowork task, or a chat on a computer that cannot run Cowork. Administrators must set both retention periods (how long chats and Cowork tasks are kept) because Cowork tasks follow their own. A watch item rather than a task: it matters if you manage settings for other people. Ask the administrator if you want the old split.

What to watch

The old per-tab switches are being phased out; people still using them see a warning from 17 November. Code-only setups keep the old behaviour until 17 December.

CoworkWATCH10 Nov
Windows: Claude moves its data to a new folder, and may now stop at launch with a message
On Windows 10 (version 21H2 or later) and 11, the update moves Claude’s saved data to a new folder. If another program holds a file Claude needs, Claude can stop at launch with “Claude could not start”.
●●●●● 5/5
The details

The data moves to the folder Claude-Data under your local application data folder. Closing other programs or restarting fixes the launch message; when Windows starts Claude at sign-in it stops without any message. Computer use now asks for the “Use system shortcuts” permission before pressing the Windows key with Tab, a number or a symbol, and file types that install something at a double click are refused. The Microsoft Store version and copies installed by a company are unchanged. Also fixed: Run on startup for Store installs, two files saved to Downloads at the same moment losing one, an artifact in the side panel reloading and losing unsaved edits, and sign-in links that did nothing when clicked twice. Not stated: whether old data is deleted after the move, so do not clean up the old folder until you have checked.

Your stack: Claude Code 2 stories

Claude CodeTRYTOP9 Nov
Update Claude Code: a leak of sign-in secrets and two permission gaps were closed
The 9 November release stops secrets such as refresh tokens from being sent to another server when a connected service redirects the sign-in. It also closes two permission gaps.
●●●●● 5/5
The details

Refresh tokens are stored keys that keep you signed in. The release closes a case where a read-only command ran outside the protected area where commands are tested, without asking, and makes file-copy commands obey the same blocked-list as file writes; commands typed with their full file location, such as /bin/cp (the copy command), now get the same checks. Also fixed: a file-editing command on network folders that could change only the first of several matching places or overwrite the first section of a notebook file. The notes list 74 fixes; these are the ones that touch your security. They name no outside report and no known misuse. Where: Claude Code, terminal and desktop Code tab. Updating is the whole action.

Claude CodeWATCH9 Nov
Claude Fable 5.2 is now the default Fable model, and saved Fable 5.1 choices were moved to it
If you picked Fable 5.1 in Claude Code, the pick now points to the newest Fable. On Pro and Max plans this happened at once; on Team and Enterprise it waits for the organisation.
●●●●● 5/5
The details

The changelog lists a price of $8 per million input tokens and $40 per million output tokens (tokens are the small pieces of text the model reads and writes). To go back, use the model command with the 5.1 name. The same release lets a Code tab session in the desktop app send twice as many messages to your other sessions (20, up from 10) before waiting for you. Nothing in the notes says how Fable 5.2 uses your plan allowance compared with 5.1; a search found no developer reaction yet. The model itself belongs to the Frontier Tech briefing. Watch your usage meter and switch back if costs jump.

What the others are building 2 stories

DevinGAP11 Nov
Devin can now set itself reminders to pick a task up again later
Devin, a rival AI coding assistant, can wake itself at a future time, including in sessions started by automations or by an automated account. A long job can pause, wait for something outside and carry on without you.
●●●●● 5/5
The details

What Claude offers today: partly. Scheduled tasks and a repeat command exist; a task choosing its own wake-up time is not described. A cloud Claude Code session already warns that a repeat timer stops when the cloud machine it runs on shuts down and offers a version that survives (Claude Code changelog, 6 Nov), so the problem is known. The Devin note is one line with no limits on how far ahead a reminder can be set. Not known: whether Devin keeps its state while waiting, or what it costs. Read-across: expect scheduled Cowork and Claude Code runs to be able to set their own follow-up time rather than only run on a fixed schedule [inference]. Signal: one vendor.

  1. The loud news is in Claude chat, the useful news is in Cowork. Sheets and whiteboards are new but beta and unproven; the scheduled-task status is small and answers the question you had last week about runs nobody watches.
  2. Update Claude Code again. The 9 November release closes a sign-in secret leak and two permission gaps, and quietly moves Fable 5.1 choices to 5.2.
