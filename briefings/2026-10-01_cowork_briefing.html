25 Sep – 1 Oct 2026 · what you can do differently, and what the others are building

Briefing summary

Claude Code now asks you less before acting; OpenAI launches assistants that never stop

Anthropic spent the week on how often Claude has to ask before it acts, mostly in Claude Code. OpenAI's developer conference pushed assistants that keep working without being asked. Both moves point the same way: you give the instruction, the tool carries on.

How to read the tags. On your own tools: TRY worth an hour this week, on the task named; WATCH it has shipped, but check the point named or wait for it; SKIP shipped, not for you. On other companies' tools: CLAUDE HAS IT Claude already does this; GAP Claude lacks it or has only part of it; NO READ-ACROSS a real feature that says nothing about what Claude will do next.

The new-chat menu now lets you choose a Google Doc, Sheet or Slides deck as the result

In the Claude desktop app, when you start a new chat and Google Drive is connected, you can pick Google Doc, Google Sheet or Google Slides as the form of the answer. You get a Google file instead of text to paste. Nothing says yet whether the same menu exists in the phone app.

Cowork

Anthropic / Cowork TRY 29 Sep

The shortcuts that create Word, PDF, PowerPoint and Excel files work again in Cowork

Cowork is Claude's desktop assistant for tasks on your computer. Typing /docx, /pdf, /pptx or /xlsx there was being rejected with an “unknown skill” message and the four had disappeared from the list that appears when you type /. They are back. Claude Code, for its part, no longer lists commands that only work in Cowork.

If /docx failed for you this month, try again on your next contract summary or board paper.

Anthropic / Cowork WATCH 29 Sep

Saving a skill that Claude proposed could wipe it: the update stops that

When Claude proposes or writes a skill in a chat, it shows a Save button under it. That button could be used on a skill with no content, which saved an empty skill, or emptied the skill it was meant to update. The button now says why it cannot save.

Update the app, then open each skill you changed recently and check it is not empty. Emptied skills are not restored by the update.

Claude Code

Anthropic / Claude Code WATCH 28 Sep

Claude Code now opens in auto mode however you pay for it

Auto mode means Claude decides itself which actions are safe and asks you only about risky ones, such as deleting files. It has been the starting mode on the Pro, Max and Team plans since 14 August. On 28 Sep it was extended to every plan, including companies that run Claude through Amazon or Google cloud, in Claude Code in the terminal and in Visual Studio Code (a code editor).

A new answer, “Yes, but ask again next time”, lets you allow one look at a file outside your project, once.

Anthropic / Claude Code WATCH 28 & 29 Sep

Max thinking is now per session, and Ultracode is a separate switch

Effort is the setting for how long Claude thinks before answering; Max is the highest level. In the desktop app, choosing Max now applies to the current session only, so new sessions no longer start at Max. Choose Max at the start of a hard task; it no longer sticks.

Ultracode is a separate switch in the terminal and no longer changes your effort level. Anthropic's notes do not explain what it does.

Anthropic / Claude Code WATCH 29 Sep

Archiving an old Claude Code session in the desktop app could delete unsaved work: fixed

Claude Code can give each session its own isolated copy of your project, called a worktree, so two tasks cannot overwrite each other. Archiving an old session could delete unsaved work in that copy. The 29 Sep update fixes this and no longer deletes a session's copy automatically.

Update the app. Before archiving an older session, copy out anything not yet saved to the project's version history.

What the others are building

Codex · Cursor GAP 23 & 29 Sep

Two companies now sell an assistant that checks your code for security problems and drafts the fix

Codex is OpenAI's coding tool; Cursor is a code editor built around AI agents. On 29 Sep OpenAI announced Codex Security as generally available: it checks your code for security problems, on demand or on a schedule, and drafts fixes in the cloud. Cursor's Security Review, six days earlier, flags typical security mistakes in each proposed code change and suggests a fix.

Read-across. Claude reviews code changes but does not scan on a schedule and fix by itself; this is likely to come (our reading).

Context & background. Both products address the weak point of code written by agents: nobody reads every line. A second agent whose only job is to look for what the first got wrong is the answer both chose.

GitHub Copilot GAP 30 Sep

GitHub's Copilot can now choose between models itself and have a second model check the first

Copilot is GitHub's coding assistant. Its new HydraFusion option, in Visual Studio Code and the Copilot app, picks per task between three routes: one model solves it, a cheaper model tries first and a stronger one steps in if needed, or other models review the answer. It shows live progress.

Read-across. Claude Code lets you choose a model but not one combined option, so expect model choice and review passes to become a setting there (our reading).

Editor's view

  1. The change to notice is in Claude Code. Auto mode as the opening mode on every plan, the “ask again next time” answer and the quieter Remote Control prompt share one idea: fewer prompts when you are at the computer, and questions kept for when someone else is instructing.
  2. The competitor week was OpenAI's. Three of the five items come from its developer conference on 29 Sep: security scanning, an app store and always-on assistants. Claude has a partial or very new equivalent of each.
  3. The direction: unattended work, steered from elsewhere. Claude's own changes and the competitors' interrupt-while-it-works features both make long runs easier to leave alone and easier to redirect. The visible gap is in timing: Claude's tasks run on a timer, while competitors are moving to assistants that run when something happens (our reading).

A quiet week for chat and Cowork, a busy one for permissions: the tools are learning when not to ask.
