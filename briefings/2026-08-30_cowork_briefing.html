Anthropic / Claude Code TRY Aug 27–28, 2026 · v2.1.248 & v2.1.251

Six security fixes land across two releases — a symlink bypass, a plugin path-traversal hole, and a Bash arithmetic loophole

v2.1.251 (Aug 28) shipped five fixes in one release: file tools (Read, Write, Edit) could be tricked into reading or writing outside an approved directory if a symlink was swapped in after the permission check ran; a plugin's declared command path could point outside its own plugin directory (now rejected as path traversal); project settings could enable detailed beta tracing or raw API body logging and bypass the OTLP collector; the Workflow tool could read a scriptPath outside the session's read permissions before the permission check fired; and Grep/Glob weren't applying Read() deny rules to files reached through a symlinked search path. A day earlier, v2.1.248 fixed Bash permission checks auto-approving commands that assigned arithmetic expressions to integer shell variables (e.g. OPTIND=1/0) — a gap a crafted command could have used to slip past an allow-rule.

None of the six is a disclosed CVE with a public advisory the way April's deny-rule bypass or this summer's API-key-exfiltration flaw were — these read as proactive hardening found and closed internally, not incident response.

Context & background. Last edition's Home Stack card tracked the wildcard Bash-rule warning and plugin auth-token approval gate from v2.1.246 (Aug 25) as the same failure class — untrusted content or configuration reaching a session unnoticed. This window's symlink-swap and path-traversal fixes are the next entries in that same pattern: a check that passes at approval time but no longer holds by execution time.

The details. The symlink bypass is the sharpest of the six: it means a permission grant for one path could, after a symlink swap, resolve somewhere else entirely at the moment the file tool actually acts — the class of time-of-check-to-time-of-use bug that's hard to catch in review because both the check and the action look correct in isolation. The plugin path-traversal fix matters most for anyone installing third-party plugin marketplaces rather than writing plugins locally, since it closes a route by which an installed plugin's declared command could reach files never intended to be in scope.

Why it still matters. Worth the hour: update to v2.1.251 or later before running any session with symlinks in the working directory, non-default plugin marketplaces, or the Workflow tool against untrusted scripts — none of the six fixes require a config change to benefit, only the update itself. No public CVE means no advisory to forward, so this is the kind of fix that's easy to miss without reading the changelog directly.

Anthropic / Claude Code TRY Aug 27–28, 2026 · v2.1.248 & v2.1.251

A new --restricted flag strips Claude Code down to file and search tools — plus two breaking defaults worth checking before they surprise you

v2.1.248 (Aug 27) added --restricted (and CLAUDE_CODE_RESTRICTED=1): it removes the built-in Bash/code-execution and WebFetch tools unless explicitly named in --tools, keeps file tools confined to the working directory, refuses bypassPermissions outright, and ignores user/project/local settings files entirely — a locked-down mode aimed at running Claude Code against untrusted repos or in CI where you don't want it to be able to shell out. Alongside it, two breaking changes from v2.1.251 (Aug 28): seat-based Enterprise subscriptions now default to Opus 5, matching every other premium plan; and CLAUDE_CODE_SUBAGENT_MODEL now only sets a default rather than overriding — an agent definition's own model: field and any explicit per-spawn model now take precedence over it.

The subagent-model change specifically inverts prior behaviour: anyone who set that environment variable expecting it to force every subagent onto one model will now see per-agent overrides win instead.

Context & background. This sits next to auto mode (default since Aug 14) rather than replacing it: auto mode is a classifier deciding what to approve automatically inside a normal session, while --restricted removes entire tool categories before the session starts — a different, coarser control aimed at the case where you don't trust the working directory's contents at all, not just the commands a well-behaved agent might run.

The details. Ignoring user/project/local settings files is the detail worth noting most: a restricted session can't be reconfigured back to a looser posture by anything sitting in the repo it's pointed at, which is exactly the property you'd want for scanning an untrusted clone or running inside CI on a fork's PR branch.

Why it still matters. Worth the hour: try --restricted the next time this pipeline needs to point Claude Code at a repository or archive it doesn't fully trust — Pet Food supplier documents from outside parties are the most likely candidate. Separately, grep this pipeline's own scripts and CI configs for CLAUDE_CODE_SUBAGENT_MODEL before the next subagent-heavy run, since the semantics just flipped.

Across the stack

Cursor WATCH Aug 27, 2026

Cursor drops the repo requirement for cloud agents — prompt first, save to a repo only once there's something worth keeping

Cursor's cloud agents no longer require connecting GitHub or another SCM before starting: a new "Start from scratch" option in the repo picker lets an agent begin working immediately, with Cursor silently creating an Origin repo behind the scenes; only when the result is worth keeping does "Create repo" save it under a chosen name and visibility. The same release adds live browser preview by port-forwarding the cloud agent's environment directly, plus one-click Vercel publishing for a live URL.

This is an onboarding-friction fix, not a capability addition — everything it enables was already reachable by connecting a throwaway repo first.

Context & background. Two editions ago this briefing tracked Cursor's push into standing, subscribed cloud agents ("swarms," a /goal command); this window's change is smaller in ambition — it's about the first five minutes of using a cloud agent, not what it does once running.

The details. The Vercel-publish path requires a Vercel account, so the "zero setup" framing has one exception baked in for anyone who wants a shareable URL rather than just a saved repo. No independent writeup of this specific feature has surfaced yet; the only source is Cursor's own changelog entry.

Why it still matters. No action: this pipeline's work starts from an existing repository or file set in essentially every case, so the friction this removes doesn't apply here. Trigger to revisit: a future project that genuinely starts from a blank prompt rather than existing source material.

GitHub / Copilot WATCH Aug 27–28, 2026

GitHub tightens Copilot billing to upfront-only and drops the 300-file limit on Copilot code review

Two changes land together: from October 1, 2026, existing Copilot Business/Enterprise customers on credit card or PayPal move to upfront per-seat payment before access, and new sign-ups reopen September 1 under the same model — GitHub frames it as tightening account vetting and billing reliability. Separately, Copilot code review drops its prior 300-file / 20,000-line-of-code ceiling entirely, now reviews bot-authored and Copilot-cloud-agent pull requests with a full agentic pass instead of a limited fallback, and adds a three-option resolution-reason dropdown (Addressed / Won't fix / Incorrect) on review comments. The default review depth also shifts from Lite to Balanced on September 28.

The billing change is administrative; the review-scope change is the one with a real capability delta, since a 20,000-line ceiling would have excluded most large refactors and monorepo changes from automatic review entirely.

Editor's view

  1. A short window found real substance in maintenance, not launches. Six security fixes across two Claude Code releases and a new lockdown flag are the kind of changes that never make a keynote but genuinely change what's safe to point the tool at — a symlink-swap bypass in file tools is a sharper finding than most of what got TRY-rated in busier weeks.

The Enterprise default-model flip and the CLAUDE_CODE_SUBAGENT_MODEL semantics change both landed in v2.1.251 alongside the five security patches — a reminder to read a release's full changelog even when the headline is "security fixes," since defaults change quietly in the same breath.
  3. Everyone else moved on plumbing, not capability. Cursor's zero-repo cloud agent onboarding and GitHub's Copilot billing overhaul are both about removing friction from getting started or getting paid — neither changes what the tools can do once running, which is consistent with a short, quiet window rather than a gap in coverage.

Wildcard for the week: GitHub uncapping Copilot code review's file-size ceiling is a bigger deal than the billing news it shipped alongside — a 300-file limit meant most real refactors never got automatic review at all, and that's now gone.
