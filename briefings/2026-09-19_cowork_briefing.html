Briefing summary

Chat and Cowork merge into one Claude; Claude Code learns to run parallel sessions

Anthropic folded Cowork into ordinary chat and gave Claude Code a way to run several coding sessions from one goal. Away from Anthropic, two rivals let you talk to a coding agent out loud in the same week — a signal worth watching, not a verdict.

Your stack

Claude chat

Anthropic / Claude chat TRY 16 September 2026

Cowork and ordinary Claude chat are no longer two separate apps

Until this week, a task you started in Cowork (Anthropic's longer-running, computer-using mode) stayed in Cowork, and a chat conversation stayed in chat — you had to pick the right app before you typed. Claude now decides for itself whether a request is a quick answer or a longer job, and both kinds of session live in the same place, on the web, desktop and mobile.

Document writing (Claude Docs), slide drafting with a PowerPoint or PDF (portable document format) export (Claude Slides), and visual design work now sit inside the same conversation too, instead of being separate tools you had to switch to.

Context & background. Cowork launched as Anthropic's separate app for longer, computer-using tasks — the kind that keep working after you stop typing. Chat stayed the place for ordinary back-and-forth conversation. Anthropic's own write-up admits the split confused people: "what they'd started in one also didn't carry into the other. So we stopped making you choose." Simon Willison, who writes one of the most-read independent accounts of these tools, said he had been "increasingly confused" by the boundary between Cowork, chat and Claude Code, and welcomed the merge as Claude becoming a general-purpose agent rather than three separate products.

The details. There is nothing to turn on. Pro and Max subscribers get the merged experience first, rolling out over the next few weeks; Team and the free plan follow later, and Enterprise organisations get at least 30 days' notice before it changes for them. Claude still asks for approval before it acts by default; you can also let it work with fewer check-ins and only interrupt you when it genuinely needs a decision — either way, Anthropic says, "you keep the final say."

Why it still matters. This is the first time the boundary between "quick chat" and "long unattended task" has been removed rather than just made easier to cross. It also explains two other changes in this briefing: Claude Code's Projects redesign and the syncing of skills and plugins into terminal sessions are the same tidying, applied to Claude Code.

Cowork

Anthropic / Cowork TRY 17 September 2026

Cowork stopped crashing on very long conversations

If a Cowork session went on for a long time — a big research pass, a multi-file review — search and reloading that session could crash the app outright. That is fixed. A second fix in the same update stops workspace updates failing with a false "not enough disk space" error on machines that in fact had plenty of room.

Context & background. Cowork keeps a working session open for as long as a task runs, sometimes hours. The longer a conversation grew, the more likely search inside it, or simply reopening it, was to bring the whole app down — a problem that got worse the more useful the session had been.

The details. It also fixed two things you may have hit: some installed plugin skills failing to load, and Cowork skills that build spreadsheets or slide decks sometimes failing to start.

Why it still matters. None of this changes what Cowork can do; it changes whether it stays usable once a session runs long, which is exactly the kind of session the merge with chat is about to make more common.

Claude Code

Anthropic / Claude Code WATCH 17 September 2026

Projects can now run several of its own Claude Code sessions toward one goal

Projects used to be a folder that held related files and conversations. It has been rebuilt around a goal instead: you describe what you want done, and Claude scopes the work, splits it across several parallel sessions (each on its own branch of a repository), reviews what each one produced, and assembles the result — you can watch the overall progress or open any one thread. Project-level settings such as cloud environments, connectors and plugins, and which model or effort level to use, now live in one place too, along with a library of every file and artifact the project has produced.

This is starting as a beta for a first group of Pro and Max subscribers who already use Claude Code's cloud sessions, expanding to more Claude Code users within about a week, with Team and Enterprise plans following later.

Context & background. The old Projects were closer to a shared folder: you put files and conversations in one place so a team could find them, but coordinating several strands of the same piece of work still meant opening separate sessions yourself and copying context between them by hand.

The details. A project now keeps shared memory across its threads — earlier decisions and how you like to be kept informed carry over automatically — and you can set a project-level goal such as "reduce this service's response time" or "retire this old interface" and let Claude break it into parallel work. No toggle is needed once it reaches your account; existing projects keep working as before until then.

Why it still matters. This is a genuinely new way of working, not a bigger folder, so it is worth watching rather than acting on until it actually appears in your account: the trigger is Projects showing a goal field and a threads view instead of the current file list, on a session that uses Claude Code's cloud environments.

Anthropic / Claude Code WATCH 17 September 2026

Skills and plugins you turned on in the Claude app now follow you into the terminal

Whatever skills and plugins you have enabled on your claude.ai account now sync automatically into Claude Code sessions signed in with that account — you no longer have to install the same thing twice to use it from the terminal. It is on by default; two settings switch it off separately for skills and for plugins if you would rather keep the terminal on its own set.

Context & background. Before this change, a skill or plugin lived wherever you turned it on: enable something in the Claude app and Claude Code would not know about it, and vice versa. That was already an odd mismatch and became a harder one to justify the same week chat and Cowork stopped being separate places too.

The details. The same update also let a terminal session sign in and immediately request access to your claude.ai plugins as part of login, and added a way to install a plugin straight from a named marketplace with one command instead of adding the marketplace first.

Why it still matters. This is a WATCH rather than a TRY because there is nothing to actively do — it is worth knowing about mainly so a skill behaving differently in the terminal than expected has an obvious explanation: check whether it is syncing from your account rather than installed locally.

What the others are building

Codex CLI Devin GAP 16–17 September 2026

Two coding agents let you talk to them out loud while they work

OpenAI's Codex CLI (command-line interface) added an experimental voice mode: a live conversation with transcripts and microphone controls, right inside the same tool that writes and runs code. A day earlier, Devin added voice calls built on a live speech model, dropping you straight into call controls the moment you start one.

Read-across. Two agent-coding tools adding a voice option in the same week is a signal, not a coincidence; expect a voice mode for Claude Code sessions to be on Anthropic's list next [inference].

Context & background. Voice input already exists in general chat assistants; what is new here is putting it inside a tool built for writing and reviewing code, where the previous norm was typing and reading a transcript. This voice mode in the Codex CLI (command-line interface) is explicitly experimental and ships alongside plainer additions in the same release: the ability to hide, archive or delete individual tasks, and Touch ID (Apple's fingerprint check) confirmation for tool requests on supported Macs.

The details. Devin's voice calls also arrived with two smaller, related changes: a session that had gone to sleep now starts waking up as soon as you begin typing, rather than after you send the message, and copying a message out of Devin now keeps its formatting when pasted into an email, document or code editor.

Why it still matters. Neither vendor has published usage data showing voice caught on, so this is a feature to watch rather than a verdict on whether talking to a coding agent works well in practice — the case for Claude Code would be the same one both vendors are making: fewer moments where you have to stop and type when your hands are on something else.

GitHub Copilot Devin GAP 16–18 September 2026

Automated code review is quietly becoming stricter by default

GitHub Copilot's code review now sorts its own findings into "open", "resolved since last review" and "previously missed", and closes its own comments once a later push addresses them, tagging why ("fixed", "won't fix", "incorrect"). The same week, Devin made security-bug scanning a permanent part of every review it runs, rather than something you had to ask for.

Read-across. Two competitors tightening their default review behaviour in the same week suggests "always scan, always track what's resolved" is becoming the baseline reviewers are expected to meet [inference].

Context & background. Automated pull-request review from a coding agent has existed for a while at all three vendors; the change this week is about trust in the machinery around it — whether a reviewer remembers what it already told you, and whether a security pass happens every time or only when asked.

The details. Copilot's update also has it write a suggested commit title and description when you accept a batch of its suggestions. Anthropic's own Claude Code changelog in the same window includes fixes to its Code Review product that carry the same intent — for example, stopping a follow-up review from re-raising a security finding a person had already resolved when a later push simply moved the lines it was anchored to — which is the evidence behind the "partly" rating above, even though Anthropic has not stated a default-on security-scan policy the way Devin has.

Why it still matters. None of this is a reason to switch reviewers; it is a reason to expect Claude's own review product to say explicitly, before long, whether security checks run on every review by default.

Editor's view

  1. The three surfaces are becoming one. Chat and Cowork merged into a single app on 16 September, skills and plugins now sync from the app into the terminal, and Claude Code's redesigned Projects turns one goal into several of its own sessions. None of these were announced as a package, but together they are the same move: fewer separate tools, one Claude that decides which mode a task needs.
  2. Rivals are converging on the same two things at once. Codex CLI (command-line interface) and Devin both let you talk to a coding agent out loud in the same seven days; Copilot and Devin both made automated review carry more memory and more default security scanning. Two vendors moving the same way in one window is a pattern, not a launch.
  3. The direction read: voice and stricter default review are the predictable next stops for Claude Code. Anthropic's own review product already tracks resolved findings across pushes, which is most of the way to what Copilot and Devin just shipped; voice is the bigger gap, and the one this week's competitor moves make hardest to ignore [inference].

Three log-ins just became one. Don't be surprised if the terminal is next.
